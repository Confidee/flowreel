# flowreel brand assets

The flowreel logo: a reel whose three frame segments circle a play
triangle. Every file is an SVG with its text outlined (no fonts needed),
except the social preview, which is also a PNG.

## Files

| Use                                | Light background                 | Dark background                 |
| ---------------------------------- | -------------------------------- | ------------------------------- |
| Logo with name, side by side       | `flowreel-mint-horizontal-light` | `flowreel-mint-horizontal-dark` |
| Logo with name, stacked            | `flowreel-mint-stacked-light`    | `flowreel-mint-stacked-dark`    |
| Symbol only                        | `flowreel-mint-symbol-light`     | `flowreel-mint-symbol-dark`     |
| Name only                          | `flowreel-mint-wordmark-light`   | `flowreel-mint-wordmark-dark`   |
| One colour (print, stamps, badges) | `flowreel-*-mono-black`          | `flowreel-*-mono-white`         |

- `flowreel-mint-favicon.svg`: the symbol for browser tabs; it switches to
  the dark-mode colour by itself.
- `flowreel-mint-avatar.svg`: the white symbol on a mint square, for
  profile pictures and app icons.
- `flowreel-social-preview-1280x640.png` (and `.svg`): the link preview
  image (the repository's Settings -> Social preview).

## Colours

## Using the logo

- Use the files as they are: do not recolour, stretch, rotate, outline or
  add effects, and keep clear space around the logo at least as wide as
  the play triangle.
- Below 24 px, use the symbol alone.
- You may use the name and logo to refer to flowreel, for example in an
  article, a talk, or a list of tools your project uses. Do not use them
  in a way that suggests the copyright holder named in [NOTICE](../../NOTICE)
  endorses your project, or as part of your own product's name or logo.
